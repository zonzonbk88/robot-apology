A robot apologizes for one specific mistake, and names the lesson, for the make.fun `u-suga-the-robot-apology-dd96bb59` bounty:

> I'm sorry I ran the vacuum under her crib at 6 a.m., ten minutes after you finally got her to sleep.
I learned that quiet hours are not a suggestion, so now I check her sleep schedule before starting any motor.

## Run it

```sh
python3 main.py
```

Python 3, standard library only. Writes the two-line apology to `/output/entry.txt` (209 characters, valid UTF-8, exactly two lines).
